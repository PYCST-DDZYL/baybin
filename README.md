# BayBin｜湾区垃圾分类助手

BayBin 帮你按湾区城市规则判断垃圾怎么扔。可以用手机拍照、文字查询，也可以戴上 Rokid 眼镜按键识别，查看垃圾桶和处理步骤。

例如，San José 独立住宅的厨余：

```text
黑桶
先倒出食物，再查空盒
```

## 能做什么

- 按独立住宅居民收运规则查询：覆盖 Cupertino、San José、Palo Alto、Los Altos 和 Berkeley，重点完善 San José。
- 使用千问识别物品，再根据城市和清运公司的公开规则给出投放建议，并提供官方来源。
- 手机直接拍照或从相册选图；缺少信息时，可补充食物内容、回收编号等，支持取消和失败重试。
- 免费离线文字查询无需 API Key；San José 的电池、荧光灯、电子垃圾可打开已核实的官方投放预约。
- 支持中英文，API Key 在手机上加密保存，不写入安装包。

## 怎么用

1. 安装手机端，在设置中确认城市、住房类型和居民清运服务。公寓、商业及其他服务暂不套用当前规则表。
2. 可先免费使用文字查询；拍照或相册识别需要填写自己的千问 API Key。
3. 使用眼镜时，再安装眼镜端并连接，对准一个物品按戒指右键。信息不足时可在手机上补充，或查看官方指南。

照片会通过手机发送到千问，因此照片识别需要联网。云端免 Key 限额试用尚未开通。

## 项目说明

使用 Kotlin 开发，包含 Android 手机端、眼镜端、共享蓝牙通信协议和城市分类规则表。当前手机端版本为 **v0.6.1**。

照片识别尚未达到 90% 目标；最新锁屏设备诊断和待完成的真机验证见 [测量记录](docs/MEASUREMENTS.md)。
