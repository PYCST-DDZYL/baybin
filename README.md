# BayBin｜湾区垃圾分类助手

戴上 Rokid 眼镜，对准要扔的东西，按一下戒指右键，就能在眼镜上看到该放哪个垃圾桶，以及投放前需要做什么。

```text
绿桶
先倒出食物，空盒再拍
```

## 能做什么

- 按城市查询分类规则：支持 Cupertino、San José、Palo Alto、Los Altos 和 Berkeley。
- 使用千问识别物品，再根据城市和清运公司的公开规则给出投放建议，并提供官方来源。
- 没有眼镜也能用：手机相册选图识别，支持取消和网络失败后重试。
- 支持中英文，API Key 在手机上加密保存，不写入安装包。

## 怎么用

1. 安装手机端和眼镜端应用，在手机上填写自己的千问 API Key。
2. 选择所在城市，连接眼镜，对准一个物品，按戒指右键拍照。
3. 查看眼镜上的分类结果；提示不确定时，按要求重拍或查看官方指南。

照片会通过手机发送到千问进行识别，因此需要联网。眼镜负责拍照和显示结果。

## 项目说明

使用 Kotlin 开发，包含 Android 手机端、眼镜端、共享蓝牙通信协议和城市分类规则表。当前手机端版本为 **v0.5.0**。

项目仍在完善，识别准确率尚未达到 90% 验收目标，v0.5.0 的新界面交互也尚未完成真机验证。
